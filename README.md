# 🎮 Tic-Tac-Toe Game

A simple and interactive Tic-Tac-Toe game built using **HTML, CSS, and JavaScript**. Two players can play against each other, and the game automatically detects the winner or a draw.

## 🚀 Features

- 🎯 Two-player gameplay (O and X)
- 🏆 Automatic winner detection
- 🤝 Draw detection
- 🔄 Reset Game functionality
- 🆕 New Game functionality
- 🎨 Simple and interactive user interface
- 📱 Responsive design (if implemented in CSS)

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎮 How to Play

1. Open the game in your browser.
2. Player O starts the game.
3. Players take turns selecting empty boxes.
4. The first player to get three marks in a row, column, or diagonal wins.
5. If all nine boxes are filled without a winner, the game ends in a draw.
6. Click **Reset Game** or **New Game** to play again.
